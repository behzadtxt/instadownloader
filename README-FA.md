# Insta Downloader (Android)

اپ ساده فارسی برای دریافت لینک ویدیو/پست عمومی اینستاگرام با yt-dlp-android.

## ساخت APK فقط با گوشی
1. فایل ZIP را از حالت فشرده خارج کن.
2. در GitHub یک مخزن جدید با نام `InstaDownloader` بساز.
3. محتویات پوشه را در ریشه مخزن بارگذاری کن (ساختار `.github/workflows/android.yml` حفظ شود).
4. وارد تب **Actions** شو و اجرای `Build Insta Downloader APK` را باز کن.
5. پس از سبز شدن اجرا، از بخش **Artifacts** فایل `InstaDownloader-debug-apk` را دانلود و از حالت ZIP خارج کن.
6. فایل APK را روی گوشی نصب کن.

## نکته فنی
این پروژه از کتابخانه `dev.ffmpegkit-maintained:yt-dlp-android:2.0.2` و لایه سازگاری API استفاده می‌کند. کتابخانه فعلی به Android 7+ و معماری arm64-v8a یا x86_64 نیاز دارد. حجم خروجی به‌دلیل بسته‌بندی Python و yt-dlp زیاد است.

فایل‌ها در فضای اختصاصی برنامه ذخیره می‌شوند؛ برای دیدن آن‌ها از فایل‌منیجر ممکن است لازم باشد وارد Android/data شوید.

## محدودیت
اینستاگرام ممکن است دسترسی بدون ورود را محدود کند یا ساختار سایت را تغییر دهد. دانلود محتوای خصوصی یا نیازمند احراز هویت تضمین نمی‌شود. اطلاعات ورود حساب را داخل برنامه وارد نکن.
